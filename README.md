Entry for make.fun's "One Line of Earned Pride" bounty ($5 in USDC).

The entry is a single line of earned pride: **After twelve years of night shifts mopping the school's halls, Luis stood in the back row at graduation, hands still smelling of bleach, and watched his daughter cross the stage — the floors he kept had carried her there.** A real person, a concrete scene, a long effort landing in one read — the pride is quiet because the work was.

`main.py` writes that line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints the same line to stdout. Deterministic: no network, no randomness, no clock.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
